Look and feel

Four directions, all using real garments from the new database. Each has a home strip, a filterable grid and a garment view (click any garment). Reload for a different random sample.

A · Gallery →

White, airy and image-led. Small monospace codes, almost no chrome. The garments do the talking.

 B · Archive (dark) →

Near-black with thin rules and monospace everywhere. A technical, catalogued feel.

 C · Index →

A dense museum-catalogue table with the filter tree always open on the left. Built for digging through data.

 D · Editorial →

Warm paper tone, serif headlines and an asymmetric layout. Reads like a printed lookbook.
